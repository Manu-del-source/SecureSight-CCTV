# SecureSight CCTV

Responsive Next.js starter website for a Kenya-wide CCTV and security systems service.

## Local development
- Node.js 20 or newer
- `npm install`
- `npm run dev`

## Preview checks
- `npm run build`
- Check mobile and desktop layouts.
- Test the quotation form and WhatsApp message.

## Before public launch
1. Replace the placeholder WhatsApp number `254700000000` in `app/page.tsx` with the verified business number.
2. Confirm the actual service area, response times, pricing, warranties, credentials and support promises.
3. Replace the email link if the business uses a different inbox.
4. Add a privacy notice and consent handling if enquiry data is collected or stored.
5. Test production build and deployment. This starter does not include a database or server-side enquiry storage.

## Deployment
Import this repository as a new, separate Vercel project. Keep it isolated from MaliHub, ZenPOS and SmartBiz365.
